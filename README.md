# Hospital Bed Availability System

## Introduction
The Hospital Bed Availability System is a Python-based project developed using Jupyter Notebook. It helps manage hospital bed records and check bed availability.

## Features
- Add, Search, Update, and Delete Bed Records
- Check Available, Occupied, and Reserved Beds
- Ward-wise Bed Availability
- Suggest Bed
- Emergency Bed Finder
- Bed Status History
- Daily Report Generation
- Low Availability Alert

## Technologies Used
- Python
- SQLite
- Tkinter
- Pandas
- NumPy

## How to Run
1. Install Python and Jupyter Notebook.
2. Open the `Hospital_Bed_Availability_System.ipynb` file in Jupyter Notebook.
3. Run the notebook cells in order.

## Project Objective
- Check hospital bed availability quickly and identify available, occupied, and  reserved beds in different wards.
- To maintain complete bed information such as bed number, ward name, bed type, and current status in one system.
- To easily update bed status when a patient is admitted, discharged, or a bed is reserved.
- To reduce manual work and save time by avoiding registers and improving accurate bed management.
